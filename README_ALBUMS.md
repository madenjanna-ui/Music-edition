# MaDenMusic — альбомная версия

Готово под 6 альбомов и 32 композиции.

## Важно
MP3-файлы специально НЕ входят в этот архив. Их можно загрузить отдельно в корень репозитория.

Сайт сам проверяет наличие каждого файла через `HEAD`. Пока файла нет, композиция показывает статус **«Скоро будет»** и не пытается запускать пустую ссылку. После загрузки MP3 карточка автоматически станет доступной.

### Что изменено
- Альбомная сетка и страницы альбомов.
- Кнопка «Играть всё».
- Статус «Скоро будет» для отсутствующих MP3.
- Убраны повторяющиеся `Together.png` для пяти песен: созданы отдельные обложки.
- Созданы 6 новых обложек альбомов.
- Сохранился большой плеер, мини-плеер, избранное, shuffle, repeat, вращение обложки и автопереход.
- Пути к MP3 оставлены в `songs.js`, чтобы после загрузки файлов код менять не пришлось.

## Загрузка на GitHub
Загрузите содержимое этого архива в корень репозитория. Затем отдельно добавьте MP3-файлы в корень с именами, указанными в `songs.js`.
